# Pata Voluntária — versão melhorada

Este pacote contém um site estático com HTML, CSS e JavaScript incorporados em um único arquivo `index.html`. Isso evita o problema de o CSS não carregar quando apenas parte dos arquivos é enviada à hospedagem.

## Publicar na Vercel
1. Envie `index.html` para a raiz de um repositório GitHub.
2. Importe esse repositório na Vercel.
3. Para um site estático simples, não configure comando de build.
4. Publique e abra a URL gerada.

## Observação
O formulário valida os campos no navegador, mas não envia nem armazena cadastros. As imagens são carregadas externamente e precisam de internet.
