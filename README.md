# 🌱 Conectando Pessoas — Plataforma de Voluntariado

**Tecnologia a serviço da solidariedade.**

O projeto **Conectando Pessoas** é uma plataforma web desenvolvida para aproximar voluntários de iniciativas sociais, facilitando o acesso a oportunidades de participação em projetos comunitários e incentivando o engajamento social por meio da tecnologia.

A solução busca tornar a divulgação de ações sociais mais acessível, intuitiva e organizada, permitindo que mais pessoas descubram maneiras de contribuir para a transformação da sociedade.

---

## 📌 Sobre o Projeto

A plataforma foi desenvolvida com o objetivo de demonstrar como o desenvolvimento de software pode gerar impacto social quando aliado à acessibilidade, à usabilidade e às necessidades reais da comunidade.

Por meio de uma interface simples e responsiva, o sistema apresenta informações sobre projetos sociais e oferece um espaço para que pessoas interessadas possam demonstrar seu interesse em participar de ações voluntárias.

### 🎯 Objetivos

- Conectar voluntários a iniciativas sociais.
- Facilitar a divulgação de projetos comunitários.
- Incentivar a participação cidadã e a solidariedade.
- Desenvolver uma interface acessível e intuitiva.
- Aplicar conhecimentos de desenvolvimento Front-End na criação de uma solução com propósito social.
- Disponibilizar a aplicação para acesso pela internet.

---

## ✨ Funcionalidades

- 🏠 **Página inicial:** apresentação da plataforma e de sua proposta social.
- 🤝 **Projetos sociais:** divulgação de iniciativas e oportunidades de voluntariado.
- 📝 **Cadastro de voluntários:** formulário para preenchimento de informações e manifestação de interesse.
- ✅ **Validação de formulário:** verificação dos campos preenchidos pelo usuário.
- 📱 **Design responsivo:** adaptação da interface para computadores, tablets e celulares.
- 🔊 **Interações sonoras:** utilização de efeitos de áudio para complementar determinadas ações da interface.

*Observação: as funcionalidades descritas devem corresponder aos recursos efetivamente implementados no projeto.*

## 🌐 Publicação na Internet

O projeto pode ser publicado gratuitamente utilizando o GitHub Pages.

Após configurar a publicação, a aplicação poderá ser acessada por meio de um endereço público, sem que o usuário precise baixar os arquivos ou executar o projeto localmente.

**Etapas de publicação:**

1. Acesse o repositório no GitHub.
2. Entre em **Settings**.
3. Localize a seção **Pages**.
4. Selecione a branch principal, geralmente `main`.
5. Escolha a pasta raiz (`/root`) como origem, caso os arquivos HTML estejam nela.
6. Salve as configurações e aguarde a publicação.

Após a conclusão, o GitHub disponibilizará o endereço público da aplicação.

> Importante: o GitHub Pages hospeda sites estáticos. Caso o projeto precise armazenar cadastros em um banco de dados ou processar informações em um servidor, será necessário implementar e hospedar também o back-end.
